# 计算机视觉学习系统 - 操作说明

## 一、项目简介
本系统是一个计算机视觉学习辅助工具，支持选择题练习、主观题练习及主观题AI评分功能（AI评分需依赖外部API，无API时该功能不可用）。用户可通过系统完成题目作答、提交答案并获取反馈。


## 二、运行前准备
1. **数据库目录检查**  
   运行系统前，请确保项目根目录下已存在文件夹（数据库目录默认路径为C:\Users\用户名\AppData\Local\ComputerVisionLearning）。若目录缺失，请手动创建，否则系统可能无法正常加载题目或保存答题数据。


## 三、核心功能说明
### 1. 选择题模块
- 支持用户作答选择题并提交，系统自动判断答案正误并反馈结果。
- 所有选择题的正确答案固定为选项“A”。

### 2. 主观题模块
- 支持用户输入主观题答案并提交。
- 集成AI评分系统：提交后将调用AI对答案进行评分并生成评语（**重要提示：若未配置有效的AI评分API，该功能无法使用，会提示评分失败**）。


## 四、数据库配置与题目添加
系统依赖选择题和主观题数据库存储题目，需手动添加题目至对应文件：

### 1. 选择题数据库
- **格式参考**：题目数据定义于`import_questions.py`文件，可直接查看文件内的示例（包含章节、小节、题目文本、选项等字段）。
- **添加题目**：如需增加选择题，按现有格式在`import_questions.py`中补充新题目即可（无需修改答案字段，默认正确答案为“A”）。

### 2. 主观题数据库
- **格式参考**：题目数据定义于`import_subjective_questions.py`文件，可查看文件内示例（包含章节、小节、题目文本、评分标准等字段）。
- **添加题目**：如需增加主观题，按现有格式在`import_subjective_questions.py`中补充新题目即可。


## 五、注意事项
1. 主观题AI评分功能依赖外部API，未配置API时会提示“评分失败”，属于正常现象。
2. 添加题目时需严格遵循`import_questions.py`和`import_subjective_questions.py`的格式规范，否则可能导致题目加载失败。
3. 若`database`目录或题目文件缺失，系统可能无法启动或显示空白题目列表，请检查文件完整性。
