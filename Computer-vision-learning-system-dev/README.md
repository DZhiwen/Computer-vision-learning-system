计算机视觉学习系统 - 操作说明
一、项目简介
本系统是一个计算机视觉学习辅助系统，支持选择题和主观题练习功能，并集成了主观题 AI 评分系统（需 API 支持，无 API 时该功能不可用）。用户可通过系统进行题目作答、提交答案并获取反馈。
二、运行前准备
检查数据库目录
运行系统前，请确保项目中已存在数据库目录（默认路径为C:\Users\用户名\AppData\Local\ComputerVisionLearning）。若目录不存在，请手动创建，否则系统可能无法正常加载或保存题目 / 答题数据。
三、系统功能说明
选择题功能
支持用户作答选择题并提交答案，系统会自动判断正误。
提交后可即时查看答题结果。
主观题功能
支持用户输入主观题答案并提交。
集成 AI 评分系统：提交后系统会调用 AI 对答案进行评分并生成评语（注意：若未配置有效的 AI 评分 API，该功能无法使用，会提示评分失败）。
四、数据库说明
系统依赖选择题和主观题数据库存储题目数据，需手动添加题目至对应文件。
1. 选择题数据库
格式参考：题目数据定义在import_questions.py文件中，可直接查看该文件中的示例格式（包含章节、小节、题目文本、选项等字段）。
添加题目：如需增加更多选择题，直接编辑import_questions.py文件，按照现有格式补充新题目即可。
注意事项：所有选择题的正确答案固定为选项 “A”，添加时无需修改答案字段。
2. 主观题数据库
格式参考：题目数据定义在import_subjective_questions.py文件中，可直接查看该文件中的示例格式（包含章节、小节、题目文本、评分标准等字段）。
添加题目：如需增加更多主观题，直接编辑import_subjective_questions.py文件，按照现有格式补充新题目即可。
五、注意事项
主观题 AI 评分功能依赖外部 API，若未配置 API 或 API 不可用，提交后会提示 “评分失败”，请忽略该提示或配置有效 API 后重试。
添加题目时请严格遵循import_questions.py和import_subjective_questions.py中的格式规范，否则可能导致题目加载失败。
若数据库目录或题目文件缺失，系统可能无法启动或显示空白题目列表，请检查文件完整性。
